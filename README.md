# Support for Dividend Retirement Planner

Dividend Retirement Planner is a macOS app for local retirement and portfolio planning.

## Getting Support

For support requests, bug reports, or questions about the app, open a support request here:

[Open a support request](https://github.com/NewLifePhase/dividend-retirement-planner-privacy/issues/new)

Important: GitHub support requests may be public. Do not post personal financial information, portfolio PDFs, account numbers, NRIC/passport numbers, addresses, phone numbers, or other sensitive information. If you include screenshots, redact private details first.

## What to Include

To help diagnose an issue, include:

- the app version;
- your macOS version;
- a short description of what you expected to happen;
- a short description of what actually happened;
- the steps that reproduce the issue, if you know them;
- redacted screenshots, if they are helpful.

## Before Requesting Support

For common issues, try these checks first:

- make sure you are using the latest available version of the app;
- restart the app and try the action again;
- for market data or security search issues, check that your Mac has an active internet connection;
- for PDF import issues, check that the PDF opens normally in Preview and is not password protected;
- for OCR or holdings extraction issues, try a clearer PDF or manually review the imported results.

## Data and Privacy

The app is designed to keep planning data on your Mac. PDF text extraction, OCR, and holdings-table parsing run locally on your Mac. The app may connect to public market-data services when you search for securities or refresh market data.

Read the privacy policy here:

[Privacy Policy](https://newlifephase.github.io/dividend-retirement-planner-privacy/)

## Financial Disclaimer

Dividend Retirement Planner is a planning tool. It does not provide financial, investment, tax, or legal advice. You are responsible for checking the accuracy of imported data, assumptions, forecasts, and any decisions you make based on the app.

## Response Times

Support is provided on a best-effort basis. The app is not intended for urgent, time-sensitive, or emergency financial decisions.
